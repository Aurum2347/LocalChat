# 📡 LocalChat

**Чат для локальной сети. Работает без интернета.**

---

## 🤔 Что это?

Представь: интернет пропал, а нужно срочно перекинуть файл коллеге или договориться с командой. **LocalChat** — это простое решение. Запускаешь на одном компьютере, остальные подключаются через локальную сеть. Всё.

---

## ✨ Возможности

- 💬 **Сообщения в реальном времени** — мгновенная доставка
- 📁 **Передача файлов** — документы, фото, архивы (до 500 MB)
- 👥 **Личные чаты** — пиши конкретному человеку
- 🌐 **Глобальный чат** — видно всем в сети
- 🎨 **Тёмная тема** — легко для глаз
- 🔐 **Без внешних серверов** — всё работает у тебя в сети

---

## 🚀 Как запустить

### 1. Скачай репозиторий
```bash
git clone https://github.com/Aurum2347/LocalChat.git
cd LocalChat
```

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

### 3. Запусти сервер
```bash
python main.py
```

### 4. Открой в браузере
- На этом ПК: `http://127.0.0.1:5000`
- На других устройствах в сети: `http://[IP-адрес-компьютера]:5000`

---

## 📝 Важно

| ⚠️ | |
|---|---|
| 🏠 | Работает **только в локальной сети** (Wi-Fi / Ethernet) |
| 💻 | Оптимизирован для **ПК** (браузер на компьютере) |
| 🔌 | Компьютер с сервером должен быть **включён** |
| 🌐 | **Интернет не нужен** — всё работает внутри сети |
